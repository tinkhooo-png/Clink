# 땡그랑

기록, 통계, 설정 세 가지만 있는 가계부입니다. 한 코드로 안드로이드 앱(홈 화면 위젯 2종 포함)과 웹(PC 브라우저용 가로 화면 포함)이 함께 만들어집니다. 계정으로 로그인하면 모든 기기의 기록이 실시간으로 맞춰집니다.

## 1. 구성

| 위치 | 내용 |
| --- | --- |
| `src/` | 앱 화면(기록·통계·마이), 저장소, 동기화 |
| `src/glass.js`, `src/motion.js` | 글래스 아이콘·팝업 일러스트와 모션 |
| `firebase.json` | 웹 주소(Firebase Hosting) 설정 |
| `android/` | 안드로이드 앱 (Capacitor) + 위젯 (`app/src/main/java/.../widget`) |
| `firestore.rules` | 서버 보안 규칙 (각자 자기 기록만 접근) |
| `.github/workflows/build.yml` | APK 빌드 + 웹에 올리기 |

## 2. 바로 써 보기 (계정 없이)

계정 설정 없이도 앱은 동작합니다. 이 경우 기록은 그 기기에만 저장됩니다.

```bash
npm install
npm run dev          # 브라우저에서 확인
```

## 3. 계정·실시간 동기화 켜기 (Firebase, 무료 요금제로 충분)

1. https://console.firebase.google.com 에서 프로젝트를 만듭니다.
2. **Authentication → 로그인 방법**에서 `이메일/비밀번호`를 사용 설정합니다.
3. **Firestore Database → 데이터베이스 만들기**(위치: `asia-northeast3` 서울)를 누릅니다.
4. **Firestore → 규칙** 탭에 `firestore.rules` 내용을 붙여 넣고 게시합니다.
5. **프로젝트 설정 → 내 앱 → 웹 앱 추가**에서 나온 값을 `.env.example`을 복사한 `.env`에 채웁니다.

로그인하면 그 기기에 있던 기록은 계정으로 자동으로 옮겨집니다. 인터넷이 끊겨도 기록되고, 연결되면 자동으로 올라갑니다.

## 4. 앱 만들기와 웹에 올리기 (GitHub Actions)

컴퓨터에 안드로이드 스튜디오를 설치하지 않아도 됩니다.

1. 이 폴더를 GitHub 저장소에 올립니다.
2. **Settings → Secrets and variables → Actions**에 `.env`의 6개 값을 같은 이름으로 등록합니다.
3. `main`에 올릴 때마다 **Actions** 탭에서 `Ttaenggrang.apk`를 내려받을 수 있습니다. 휴대폰에서 열면 설치(업데이트)됩니다.
4. PC는 프로그램 없이 브라우저로 씁니다. 처음 한 번만 아래를 해 두면 올릴 때마다 **https://ledger-53aeb.web.app** 이 새 버전으로 바뀝니다.
   - Firebase 콘솔 → 빌드 → **Hosting** → 시작하기(안내 화면은 끝까지 다음만 누르면 됩니다).
   - Firebase 콘솔 → 프로젝트 설정(톱니) → **서비스 계정** → **새 비공개 키 생성** → JSON 파일이 내려받아집니다.
   - GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret → 이름 `FIREBASE_SERVICE_ACCOUNT`, 값에 JSON 파일 내용을 통째로 붙여 넣습니다.
5. `v1.1.0`처럼 태그를 붙이면 **Releases**에 APK가 올라가 링크로 나눠 줄 수 있습니다.

- 웹 주소는 Firebase 기본 주소라 로그인 설정을 따로 하지 않아도 됩니다.
- Play 스토어에 올리려면 서명 키를 만들고 `assembleRelease`(또는 `bundleRelease`)로 바꿔야 합니다.

직접 빌드하려면 `npm run build`(웹, `dist/`), `npm run android:sync` 후 `npm run android:open`(안드로이드 스튜디오)을 씁니다.

## 4-1. PC 화면

- 폭 1280px 이상: 왼쪽 레일 + 2단 배치. 기록은 입력과 오늘 기록 표, 통계는 기간 패널과 카드 4개, 마이는 2단입니다.
- 768–1279px: 레일은 그대로, 내용은 한 줄. 통계 기간은 ≡ 버튼으로 엽니다.
- 767px 이하: 휴대폰 화면과 같습니다.
- 키보드: 아무 칸도 고르지 않은 상태에서 숫자를 누르면 금액, Alt+1·2·3…으로 카테고리 바로 저장, Esc로 닫기, Enter로 저장.

## 5. 위젯 (안드로이드)

- **빠른 기록(4×4)**: 키패드로 금액을 누르고 카테고리를 누르면 바로 저장됩니다. 로그인 상태면 앱을 열지 않아도 서버로 올라가 PC에 바로 나타납니다. 인터넷이 없으면 기기에 보관했다가 앱을 열 때 올립니다.
- **이번 달 요약(2×2)**: 이번 달 지출, 오늘 지출, 수입을 보여 주고 누르면 앱이 열립니다.
- 위젯에 나오는 카테고리는 마이 → 카테고리에서 숨기지 않은 것 중 위에서부터 6개입니다.
- 안드로이드 위젯은 글자 입력칸을 넣을 수 없어서, 금액 입력은 위젯 안 키패드로 만들었습니다.

## 6. 손동작

- 화면을 좌우로 밀면 기록 · 통계 · 마이 탭으로 넘어가요. 손가락을 따라 움직이고, 화면 폭의 4분의 1 넘게 밀거나 빠르게 튕기면 넘어가요.
- 기록 화면에서 맨 위에서 아래로 밀면 전날, 맨 아래(또는 스크롤이 없을 때 아무 데서나)에서 위로 밀면 다음 날로 바뀌어요. 오른쪽 위 날짜를 누르면 날짜를 직접 골라요.
- 빠른 기록 위젯은 크기를 바꾸면 키패드·카테고리 줄이 늘어나고 글자도 같이 커져요.

## 7. 디자인 기준

- Orange TDS: 버튼 규격(56px/16px), 타입 토큰 t1–t7, `primary` #c45000은 누르는 것에만, `brand` #ff803d는 3D 오브제에만 씁니다.
- 로고: 원본 2D 심볼(동전 둘 + 씨앗 둘)을 주황 단색으로 씁니다. 앱 아이콘·파비콘·레일도 같습니다.
- 2D 선 아이콘: 탭·정렬·이동 같은 조작에만 씁니다.
- 글래스 아이콘(`src/glass.js`): 꽉 찬 주황 도형 위에 반투명 유리 도형을 겹친 아이콘. 카테고리 표시(아이콘을 직접 고름), 토스트, 경고, 빈 화면, 계정 카드에 씁니다.
- 팝업 일러스트: 아이소메트릭 글래스. 첫 기록 축하, 삭제 확인, 동기화 켜짐, 월간 리포트, 위젯 안내. 한 화면에 하나만.
- 모션: 저장 시 동전 비행(550ms)·새 줄 등장, 토스트 200ms(4초 뒤 사라짐), 금액 없이 누르면 흔들림 240ms, 통계 막대 성장, 빈 화면 아이콘 떠다님. 기기에서 '동작 줄이기'를 켜면 페이드만 남습니다.
- 카테고리 색은 통계 막대·점에만 씁니다. 이모지는 쓰지 않습니다.

## 8. 나중에 할 일
